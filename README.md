• VFS Emulator — это программа, реализующая эмуляцию виртуальной файловой системы (VFS) с простым графическим интерфейсом (GUI).

Эмулятор позволяет выполнять команды, аналогичные консольным (ls, cd, exit), а также поддерживает работу с виртуальной файловой системой, загружаемой из 

CSV-файла.


Разработка ведётся поэтапно:

Этап 1 — REPL: минимальный прототип интерфейса команд;

Этап 2 — Конфигурация: добавление параметров запуска и выполнения стартовых скриптов;

Этап 3 — VFS: подключение виртуальной файловой системы с поддержкой чтения структуры каталогов и файлов из CSV.

Программа написана на Python 3 с использованием tkinter.


• Функции.

- VFSNode - Представляет узел виртуальной файловой системы.

  Поля:

name — имя узла (файла или каталога);

is_dir — признак, является ли узел директорией;

children — словарь дочерних элементов (для директорий);

content — содержимое файла в виде байтов;

owner — владелец (зарезервировано для будущих этапов).


  Методы:

add_child(node) — добавить дочерний элемент;

get_child(name) — получить элемент по имени;

list_children() — вернуть список имён дочерних узлов с указанием типа.


- VFS - Класс, управляющий виртуальной файловой системой.
  Методы:

_parts(path) — разбивает путь на компоненты;

mkdirs(parts) — создаёт каталоги по цепочке;

add_dir(path) — создать каталог;

add_file(path, content_bytes=b"") — создать файл;

resolve(cwd_parts, target) — разрешить путь относительно текущего каталога.


 - VFS_REPL_App - Главный GUI-класс, реализующий REPL (read–eval–print loop) и пользовательский интерфейс.
 
  Основные элементы интерфейса:

Окно Tk с текстовым полем вывода;

Метка текущей директории;

Поле ввода команд.


  Основные методы:

create_widgets() — создание виджетов интерфейса;

print_output(text) — вывод текста в окно;

load_vfs(csv_path) — загрузка VFS из CSV;

show_motd() — отображение сообщения дня (motd);

on_enter(event) — обработка ввода команды;

handle_line(line) — обработка и исполнение команды;

run_script(path) — выполнение стартового скрипта;

run_next_script_line() — последовательное выполнение строк скрипта.


  Команда для запуска проекта:
